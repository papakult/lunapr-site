О демонстрационном проекте

Этот сайт показывает пример дизайна и разработки из портфолио. Описания услуг и интерфейсов служат для демонстрации. Заявки, заказы и файлы через сайт не принимаются.

Функции сайта

В демонстрационной версии нет форм ввода контактов, регистрации, загрузки файлов, чатов и счетчиков веб-аналитики. Формы отправки и связанные клиентские обработчики удалены. Шрифты и используемые библиотеки загружаются с домена сайта.

Для анимации переходов используется сессионная отметка lp в браузере. Она содержит постоянное значение 1, не создает уникальный идентификатор посетителя и не отправляется кодом сайта на сервер.

Технические данные хостинга

При открытии страниц браузер обращается к хостингу GitHub Pages. Провайдер может обрабатывать IP-адрес и другие технические сведения веб-запросов для работы и безопасности инфраструктуры. Отсутствие форм и счетчиков не отключает журналы хостинга. Эта страница не утверждает полного отсутствия обработки технических данных.
